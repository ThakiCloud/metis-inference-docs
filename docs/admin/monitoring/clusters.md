# 연결된 클러스터

연결된 클러스터 화면은 이 플랫폼에 등록된 K8s 클러스터 목록과 그 연결 상태를 보여줍니다.
엔드포인트를 어느 클러스터에 배치할 수 있는지, 클러스터 연결이 끊긴 곳은 없는지 확인하는
용도입니다.

![연결된 클러스터 목록](/images/admin/admin-monitoring-clusters.png)

엔드포인트 목록과 활동 이력에서 보이는 `cluster_id` · `cluster_name` 이 바로 여기 등록된
클러스터를 가리킵니다. [전체 엔드포인트 조회](/admin/serverless/list)에서 `cluster_id`
로 필터링할 때 이 화면에서 대상 클러스터의 ID 를 먼저 확인하세요.
