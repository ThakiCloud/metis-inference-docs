# 변경 이력

이 문서 사이트의 변경 이력입니다. 플랫폼 자체의 릴리스 노트가 아닙니다.

## 2026-08-27 — API 로 운영하기

콘솔 대신 API 로 운영하려는 분들을 위해 네 페이지를 더했습니다.

[이 API 의 범위](/api/scope)는 Metis 가 다루는 것과 다루지 않는 것을 갈라 놓았습니다.
vNet·Security Group·가상 머신·VM 이미지는 인프라 제품 소관이라 여기에 경로가 없습니다.
없는 경로를 찾느라 시간을 쓰지 않도록 표로 정리했습니다.

[프로그래밍 방식 제어](/api/automation)는 인증부터 비동기 상태 폴링, 자원 수명주기 한 바퀴,
WebSocket 로그·터미널까지 자동화에 필요한 흐름을 모았습니다.

[NPU 로 서빙하기](/guide/npu)는 Rebellions NPU 의 제약을 한자리에 모았습니다. 모델 경로가
S3 전용이라는 것, HuggingFace 토큰을 넣으면 거부된다는 것, `cluster_id` 가 사실상 필수라는
것이 스펙 곳곳에 흩어져 있었습니다.

[알려진 스펙 문제](/api/known-issues)는 스펙과 서버 동작이 어긋나는 곳을 적어 둡니다.
설명에는 필수인데 `required` 배열에서 빠진 필드가 다섯 개 있고, 그중 하나가 NPU 엔드포인트를
만들 때 쓰는 `cluster_id` 입니다.

API 레퍼런스에는 인프라 모니터링 6개를 되살렸습니다. 큐 스케줄링 관리는 계속 범위 밖이지만,
클러스터·가속기 메트릭과 자원 인벤토리는 큐와 다른 관심사인데 태그만 그 아래에 있었습니다.
활용도 조회는 NVIDIA GPU 와 Rebellions NPU 를 함께 읽습니다 —
[인프라 모니터링 API](/admin/monitoring/api).

## 2026-08-25 — 최초 공개

Metis 추론 문서를 새로 썼습니다. 기존 가이드가 과거 버전 기준이었고 관리자 앱이 거의
비어 있어서, 패치하지 않고 처음부터 다시 만들었습니다.

바뀐 것 중 독자에게 실질적인 것은 두 가지입니다.

**추론 호출 방식이 명확해졌습니다.** 이전 문서는 콘솔 프록시 API 를 안내했습니다.
지금은 엔드포인트 자신의 주소로 직접 호출하는 방식을 정본으로 삼고, 프록시 세 경로는
콘솔 플레이그라운드 전용이라고 명시했습니다. 홉이 하나 줄어 지연이 낮고, OpenAI 클라이언트가
그대로 붙습니다. [콘솔 프록시 API](/guide/inference/console-proxy) 에 이유를 정리했습니다.

**관리자 앱이 문서로 들어왔습니다.** 엔드포인트 운영, 노드·사용량 추세·클러스터 모니터링,
vLLM 카탈로그, 프로젝트·시스템 설정까지 [Admin AI Inference](/admin/) 아래에 정리했습니다.
미터링·과금 영역은 아직 검증되지 않아 이번 공개에서 제외했습니다.

그 밖에 API 레퍼런스를 OpenAPI 뷰어로 붙였고(큐 스케줄링 영역은 이 문서 범위가 아니라
제외했습니다), 워크로드·볼륨·템플릿·프로젝트 화면 설명을 추가했습니다.
