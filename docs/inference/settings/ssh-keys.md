# SSH 키

계정에 SSH 공개키를 등록해 두는 화면입니다. 등록·수정·삭제 세 가지를 할 수 있습니다.

<!-- SCREENSHOT: settings-ssh-keys -->

## 등록

공개키를 붙여 넣어 등록합니다. 여러 개를 등록해 두고 필요에 따라 골라 쓸 수 있습니다.

## 수정·삭제

등록해 둔 키의 이름이나 값을 고치거나, 더는 쓰지 않는 키를 삭제합니다. 어떤 워크로드가
이 키를 참조하고 있는지는 삭제 전에 확인하는 편이 안전합니다.
