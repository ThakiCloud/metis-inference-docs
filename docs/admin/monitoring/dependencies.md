# 의존성(SBOM)

의존성 화면은 플랫폼과 그 위에서 도는 이미지가 포함하는 소프트웨어 구성 요소 목록(SBOM,
Software Bill of Materials)을 보여줍니다. 특정 라이브러리에 취약점이 발견됐을 때 우리
환경 어디에 그 구성 요소가 들어 있는지 확인하는 용도로 씁니다.

![의존성(SBOM) 목록](/images/admin/admin-monitoring-dependencies.png)

이 화면은 보안·컴플라이언스 점검의 출발점입니다. vLLM 워크로드가 쓰는 베이스 이미지의
구성을 확인하려면 함께 [vLLM 카탈로그](/admin/catalog/vllm)를 참고하세요.
