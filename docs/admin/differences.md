# 일반 앱과의 차이

Admin AI Inference 앱과 AI Inference 앱은 같은 백엔드를 보는 두 개의 창입니다. 무엇이
다른지 알아야 어느 화면에서 무엇을 해야 하는지 헷갈리지 않습니다.

## 범위가 다릅니다

AI Inference 앱은 로그인한 사용자가 속한 **프로젝트 하나**의 자원만 보여줍니다. 관리자
앱은 같은 IAM 조직 안에 있는 **모든 프로젝트**의 자원을 가로질러 보여줍니다. 엔드포인트
목록 API 를 예로 들면 일반 앱은 `GET /projects/{project_id}/endpoints` 를 부르고, 관리자
앱은 `GET /admin/endpoints` 를 부릅니다. 후자는 프로젝트를 지정하지 않고, 각 항목에 소속
`project_id` 와 `project_name` 이 함께 붙어 나옵니다.

## 관리자 앱은 엔드포인트를 만들지 않습니다

가장 중요한 차이입니다. AI Inference 앱에는 Docker · vLLM · vLLM CPU · vLLM Rebellions
네 가지 생성 화면이 있지만, 관리자 앱에는 **생성 라우트가 없습니다.** 관리자가 하는 일은
이미 만들어진 엔드포인트를 조회하고, 수정하고, 일시정지·재개하고, 삭제하는 **운영**입니다.
새 엔드포인트가 필요하면 해당 프로젝트 소유자가 AI Inference 앱에서 만들어야 합니다.

행 액션도 그래서 다릅니다. 관리자 앱의 엔드포인트 목록에서 할 수 있는 것은 Service URL
확인, 로그 보기, 프롬프트 전송, 일시정지, 재개, 편집, 삭제입니다. 일반 앱에 있는 벤치마크
실행 액션은 관리자 앱에는 없습니다.

## 관리자 앱에만 있는 화면

반대로 관리자 앱에는 프로젝트 경계를 넘어서야만 의미가 있는 화면들이 추가로 있습니다.
노드·클러스터·의존성(SBOM) 모니터링, 테넌트 전체 토큰 사용량과 비용, API 키 로스터와
이상 탐지 알림, 레이트 리밋과 가격 정책, vLLM 카탈로그, 프로젝트 관리, 사용자 스토리지
쿼터, 시스템 설정이 그것입니다. 이들은 전부 `admin` 경로 아래에 있고 일반 프로젝트 API 에는
대응하는 경로가 없습니다.

## 인증은 같습니다

호출 방식 자체는 다르지 않습니다. 관리자 API 도 플랫폼 API 이므로 로그인해서 받은 JWT 를
`Authorization: Bearer` 헤더로 붙입니다. 다만 그 토큰의 주인이 관리자 권한을 가진 계정이어야
`admin` 경로가 403 없이 통과합니다.
