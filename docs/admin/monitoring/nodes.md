# 노드

노드 화면은 클러스터를 이루는 물리 노드의 자원 현황을 보여줍니다. 어느 노드에 GPU 가
몇 장 있고, 그중 얼마가 엔드포인트에 할당돼 있는지를 확인할 때 씁니다. 새 엔드포인트를
어느 클러스터에 배치할지, 특정 클러스터의 GPU 가 바닥났는지를 판단하는 근거 화면입니다.

<!-- SCREENSHOT: admin-monitoring-nodes -->

이 화면은 별도의 공개 API 경로 없이 콘솔 화면으로만 제공됩니다. 노드 단위 수치를 코드에서
가져와야 한다면, 대신 [사용량 추세](/admin/monitoring/usage-trend)의 클러스터 단위
시계열을 참고하세요.
