# 볼륨

볼륨은 엔드포인트가 재시작돼도 남아 있는 영속 저장 공간입니다. 개념에 대한 자세한 설명은
[핵심 개념](/guide/concepts) 의 볼륨 항목에 있습니다 — 큰 모델 가중치를 매번 새로
다운로드하지 않고 볼륨에 올려 두고 여러 엔드포인트가 재사용하거나, 파인튜닝 산출물을
보관하는 용도로 씁니다.

<!-- SCREENSHOT: volumes-list -->

이 화면에서는 지금 프로젝트에 연결된 볼륨을 확인합니다. 각 볼륨이 얼마나 쓰이고 있는지,
어떤 엔드포인트가 참조하고 있는지를 여기서 파악한 뒤, 필요하면 새 엔드포인트를 만들 때
그 볼륨을 연결합니다.

Rebellions vLLM 엔드포인트처럼 모델을 `s3://` 경로로 직접 지정하는 워크로드 타입은
[워크로드 타입](/guide/workload-types) 에서 다루는 대로 볼륨과 맞물려 동작합니다 — 모델을
어디서 가져올지 정할 때 이 화면에서 확인한 볼륨 경로를 참고하세요.
