# 템플릿

같은 모델로 엔드포인트를 반복해서 만든다면, 매번 워크로드 타입·모델·리소스 사이징을
새로 입력하는 대신 템플릿에서 시작할 수 있습니다. 템플릿이 무엇을 담는지는
[핵심 개념](/guide/concepts) 에서 설명합니다.

<!-- SCREENSHOT: templates-list -->

목록에서 지금까지 만들어 둔 템플릿을 확인하고, 필요하면 새로 만들거나 기존 템플릿을
고칩니다. 행을 열면 그 템플릿에 저장된 값을 자세히 볼 수 있고, 편집 화면에서 값을
바꿀 수 있습니다.

템플릿은 엔드포인트를 만들 때 반복 입력을 줄이는 사전 설정일 뿐이므로, 템플릿을 만들거나
고치는 것 자체로는 아무 엔드포인트도 배포되지 않습니다. 실제 배포는 여전히
[엔드포인트 조회](/inference/serverless/list) 에서 이어지는 생성 화면에서 이루어집니다.
