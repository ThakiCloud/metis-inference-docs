# 벤치마크

vLLM 계열(vLLM·CPU vLLM·Rebellions vLLM) 엔드포인트의 처리량을 재는 화면입니다.
[엔드포인트 조회](/inference/serverless/list) 목록의 행 액션 메뉴에서 벤치마크를
선택해 시작하고, 이 화면은 그렇게 실행한 결과를 모아 둡니다. Docker 커스텀 엔드포인트는
서버 형태가 정해져 있지 않아 벤치마크 대상이 아닙니다.

::: tip 이 환경에서는 사이드바에 노출되지 않습니다
이 화면은 지금 이 환경의 콘솔 사이드바에는 나타나지 않습니다. 다만 라우트 자체는 살아
있으므로 주소를 직접 입력해 들어갈 수 있고, 엔드포인트 목록의 벤치마크 액션에서도
접근할 수 있습니다.
:::

<!-- SCREENSHOT: benchmarks-list -->

새 모델을 서빙하기 전에 실제 부하에서 얼마나 처리할 수 있는지 미리 확인하고 싶을 때
씁니다. 레플리카 범위나 리소스 사이징을 조정한 뒤 다시 벤치마크를 돌려 값이 어떻게
바뀌는지 비교하는 식으로 쓰면 됩니다.
