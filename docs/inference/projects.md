# 프로젝트

프로젝트는 엔드포인트·볼륨·템플릿을 담는 가장 바깥쪽 그릇입니다. 대부분의 API 경로가
`/projects/{project_id}/...` 형태인 이유도 이것이고, 이 앱에서 보는 거의 모든 화면은
지금 선택된 프로젝트 안의 리소스만 보여줍니다. 개념 자체는
[핵심 개념](/guide/concepts) 에서 자세히 설명합니다.

<!-- SCREENSHOT: projects-list -->

이 화면에서는 자신이 속한 프로젝트를 확인하고 전환합니다. 팀이나 용도별로 프로젝트를
나누어 두었다면, 리소스와 사용량 조회는 여기서 프로젝트를 바꿔 가며 확인하면 됩니다.

프로젝트를 바꾸면 엔드포인트 목록·워크로드·볼륨·템플릿·사용량까지 이 앱의 나머지 화면이
전부 그 프로젝트 기준으로 다시 보입니다. 지금 어느 화면에서 무엇을 봐도 데이터가
예상과 다르다면, 먼저 이 화면에서 프로젝트가 맞게 선택돼 있는지부터 확인하세요.
